# Login-Signup MERN Project

A full-stack **MERN (MongoDB, Express.js, React.js, Node.js)** application with **JWT authentication**, **OTP verification**, and **password change** functionality.

---

## Features

- User registration with **email verification via OTP**
- User login with **JWT authentication**
- Secure **password change** functionality
- Protected routes for authenticated users
- Frontend built with **React.js**
- Backend built with **Node.js** and **Express.js**
- Database using **MongoDB** (Mongoose ODM)

---

## Technologies Used

- **Frontend:** React.js, Axios, React Router
- **Backend:** Node.js, Express.js
- **Authentication:** JWT (JSON Web Token)
- **Database:** MongoDB, Mongoose
- **Email/OTP:** Nodemailer
- **Password Security:** bcrypt.js
- **Environment Variables:** dotenv
